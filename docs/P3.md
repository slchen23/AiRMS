# P3：路網設定檔、SVG 路網圖與即時監視頁 view2

完成日期：2026-11-03

## 內容

| 元件 | 說明 |
|---|---|
| `src/main/resources/network/network.json` | 路網設定檔：路線幾何（含里程）、58 個交流道／服務區節點、100 台 RMS 對應、8 組屏柵線、標誌與方向標示位置。座標取自簡報第 10 頁路網圖 |
| `tools/network/gen_network.py` | 產生 network.json 的腳本（座標、RMS 清單都在這支程式裡，改完重跑即可；可附現場 RMS 清單檢查有沒有漏） |
| `view/NetworkConfig` | 啟動時讀取並檢查路網設定檔，有錯列出全部錯誤後停止啟動 |
| `view/TrafficRules` | 路段速度分級（門檻可在系統設定調整）、RMS 圓圈文字（沿用舊系統規則） |
| `view/SectionCoverage`、`/api/admin/sections` | 路網路段查看頁：每筆來源路段在圖上的狀態、相鄰路段的空隙或重疊 |
| `webroot/admin-sections.html`、`js/admin-sections.js` | 管理選單「路網路段」頁（只能查看） |
| `view/ScreenlineEvaluator` | 屏柵線告警判斷（沿用舊系統，加上無效車道規則） |
| `view/LiveViewService`、`LiveViewVerticle` | 每 15 秒從資料庫整理一次即時資料放記憶體，網頁直接取用，不論幾個畫面同時開都不增加資料庫負擔 |
| `http/ViewApi` | `GET /api/view/network`（路網設定）、`GET /api/view/live`（即時資料） |
| `webroot/js/network-svg.js` | SVG 路網圖共用元件，P4 airms2、P5 query 也用這支 |
| `webroot/view2.html`、`js/view2.js` | 即時監視頁：全螢幕黑底，依視窗大小自動縮放 |
| `view/RampService`、`http/AdminApi`（`/api/admin/ramps`） | 路網匝道修改：每個匝道圈可個別隱藏、修改 RMS 代碼，存在 airms.db 的 `ramp_override`（資料庫版本 4）；畫面拿到的路網都先套用這些修改 |
| `webroot/admin-ramps.html`、`js/admin-ramps.js` | 管理選單「路網匝道」頁 |
| 系統設定 | 新增「首頁與即時監視需要登入」（2026-11-05 起預設開啟）、路段速度顏色（分級門檻、低速無車流規則、過時分鐘數）、8 組屏柵線的 VD 代碼與兩個門檻 |

## view2 畫面

- 版面依簡報：黑底、綠色路線、白色匝道圈、黃色地名、白色里程；國1、國3 交叉處國1在上。
- **路段顏色**：依路段平均速度上色（圖例在左上角）：資料不足白、0～20 紫、20～40 紅、40～60 橘、60～80 黃、80 以上綠。門檻全線統一，可在系統設定調整（見下方「路段速度顏色」），顏色固定。路段依里程對應到路線上，來源的路段切法改變也會自動對上；滑鼠移到路段上可看起訖地名、里程、速度與流量。
- **RMS 圓圈**：顯示儀控率（同舊系統：「閃黃」顯示 30、紅、綠，通訊異常顯示 X）。
  - 切格：埔鹽系統南下、苗栗北上（公館／苗栗）、龍井南下、和美南下（和美／伸港）切 2 格；霧峰南下切 3 格（上：211 環道、左下：212 環道、右下：212 國6專用道）。
  - 「外」：範圍外、沒有儀控（新竹系統、香山、西濱南下、古坑系統、古坑(北)南下）。
  - 空白圈：有匝道但目前沒有 RMS 資料（造橋北上）。
  - 大雅北上：開放資料裡沒有這台 RMS，舊 view.html 也不畫，預設不顯示（可在「路網匝道」頁打開，見下方）。
  - 滑鼠移到圓圈上可看設備代碼、原始儀控率、通訊狀態、控制模式。
- **屏柵線鈴**（8 組，位置在路網兩端）：紅鈴＝流量超過門檻、橘鈴＝連續兩期偏高、白鈴打叉＝資料異常；正常不顯示。滑鼠移上去可看換算流量、門檻與異常原因。
- **雲端提供資料時間**：速度、時制、屏柵線各來源的資料時間，超過時間沒更新顯示紅字（速度 10 分鐘、時制 5 分鐘、屏柵線 17 分鐘）；「畫面更新」是這個畫面最後一次取得資料的時間。
- **開始監控**：同舊頁，開頁載入一次，按「開始監控」後依「間隔更新時間（秒）」定時更新（預設 25 秒，可設 10～600 秒），再按一次停止。右上角可切換全螢幕。

## 判斷規則

| 項目 | 規則 | 與舊系統的差異 |
|---|---|---|
| 路段速度分級 | 速度 ≤20 且流量 0 → 資料不足；≤20 紫、≤40 紅、≤60 橘、≤80 黃、其餘綠 | 新增：速度缺值或負數（來源缺值代碼）視為資料不足，不再畫紫色；某路段比最新資料舊 10 分鐘以上（已不在來源中）也視為資料不足；門檻、低速規則、過時分鐘數可在系統設定調整 |
| RMS 文字 | 通訊狀態不是 0 → X；儀控率含「黃」→ 30、含「紅」→ 紅、含「綠」→ 綠，其餘照原值 | 新增：某台 RMS 比最新資料舊 5 分鐘以上就不顯示數字 |
| 屏柵線 | 最近 80 分鐘、最新 12 期；平均 × 12 > 小時門檻 → 紅鈴；相鄰兩期都 > 單期門檻 → 橘鈴 | 新增無效車道規則：有任何車道是 -2 或缺值的那一期不加進總量、也不算連續；最新一期有無效車道直接標資料異常 |
| 屏柵線異常 | 80 分鐘內沒資料、最新一期超過 17 分鐘、最新三期都沒有有效流量 | 新增：VD 代碼在資料中找不到時，原因寫明「VD 資料中沒有這支 VD」 |

**RMS 代碼比對**：來源 XML 有 39 台北上 RMS 的「北」用相容字（U+F963，外觀一樣但編碼不同）。新系統比對前一律做 Unicode NFKC 正規化，所以不受影響。

## 路網匝道管理（管理選單 → 路網匝道）

路網圖上全部 104 個匝道圈都列在這一頁，管理者可個別調整，不必改程式、不必重啟。
已開著的即時監視畫面重新整理後生效（之後的 airms2、query 也套用同一份）。

| 功能 | 說明 |
|---|---|
| 顯示開關 | 表格上直接切換。隱藏只影響畫面，該匝道的 RMS 資料照常收集保存 |
| 修改 RMS 代碼 | 「使用路網設定檔的設定」或「自訂」。自訂時一行一台、最多 3 台（2 台切左右兩格、3 台切上／左下／右下三格，依輸入順序）；空白表示這個匝道沒有 RMS |
| 從資料中挑選 | 列出目前 RMS 資料裡有、但沒有對應到任何匝道圈的設備代碼（例如新設的 RMS），直接加入 |
| 有資料／無資料 | 每個代碼標示目前 RMS 資料中有沒有這台，填錯或設備改名一看就知道 |
| 還原 | 回到路網設定檔的內容 |
| 篩選 | 依國道、方向，或只看已修改／隱藏的 |

- 代碼檢查：必須是 `RMS-` 開頭的完整代碼（含中文名稱部分）、不可含空白、不可重複、不可用在其他匝道圈（包含隱藏中的）；比對前做 NFKC 正規化。
- 只存跟路網設定檔不同的部分；改回跟設定檔一樣時自動清掉該筆修改。
- 每次修改、還原都記在「登入管理 → 操作紀錄」（修改路網匝道／路網匝道還原預設，列出修改前後）。
- 路網設定檔日後拿掉某個匝道時，該筆修改保留在資料庫但不套用（啟動時記錄一行警告）。
- 先前版本放在系統設定的兩個匝道開關（大雅北上、造橋北上），資料庫升級到版本 4 時自動搬到這裡。

## 路段速度顏色（系統設定 → 路段速度顏色）

全線統一一套，顏色固定（簡報的紫、紅、橘、黃、綠、白），只有門檻可調。改完立即重算，已開著的畫面下一次更新就套用，圖例文字也跟著改。

| 設定 | 預設 | 說明 |
|---|---|---|
| 速度分級門檻（公里/小時） | 20, 40, 60, 80 | 4 個數字一起填、一起存（逗號、頓號、空白都可分隔），必須由小到大、介於 1～200 |
| 低速且流量 0 視為資料不足 | 開 | 速度 ≤ 第 1 個門檻且流量為 0 時畫白色（同舊系統）；關閉則畫紫色 |
| 路段資料過時（分鐘） | 10 | 某路段比最新資料舊超過這個時間就畫白色；整個來源超過這個時間沒更新，資料時間顯示紅字 |

只影響畫面；資料庫存的是原始速度，歷史資料與下載內容不受影響。修改記入操作紀錄。

## 路網路段查看頁（管理選單 → 路網路段）

來源 XML 的路段沒有編號，只有國道、方向、起訖地名與里程；系統依起訖里程自動畫到路線上（目前 111 段：國1 南北各 25、國3 南下 31、北上 30；115 個起訖點中 114 個正好落在圖上的交流道，只有國3南下最後一段到古坑(南) 271.2K 超出圖面）。這一頁只能查看，用來核對：

- 每筆路段：路線、起點 → 終點、里程（滑鼠移上去看長度）、速度、流量、顏色、圖上狀態（完整／部分在圖外／不在圖上／圖上沒有這條路線）、資料時間。
- 點表格一列，上方路網圖會閃爍標出那一段；點圖上的路段，表格跳到那一列。寬螢幕時路網圖固定在畫面上方。
- 摘要：最新資料的路段數、完整畫在圖上、部分在圖外或不在圖上、最新資料中沒有（可能已重新切段）、同一路線相鄰路段的空隙或重疊（會列出位置）。
- 「只看需要注意的」：不完整在圖上、最新資料沒有、沒有速度的路段。
- 高公局重新切段時：舊路段標「最新資料沒有」並畫成資料不足，新路段會蓋在上面；接縫若有空隙或重疊會列在頁面上。

## 增減匝道或修改路網

1. 修改 `tools/network/gen_network.py` 裡的節點清單（里程、名稱、位置、RMS 代碼），執行：
   ```
   python tools/network/gen_network.py src/main/resources/network/network.json
   ```
   可加第二個參數給現場 RMS 代碼清單（一行一個），程式會列出設定檔漏掉或多出的代碼。
2. 也可以直接改 network.json，或複製一份放到程式外，在 config.json 加 `"networkFile": "D:/airms-config/network.json"` 指定。
3. 重新啟動。格式有錯時程式會列出錯誤並停止，不會帶著錯的設定執行。
