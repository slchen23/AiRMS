# P1：資料抓取與保存

完成日期：2026-11-02（本文件 2026-11-07 依 0.5.0 程式更新；資料保存的細節見 `docs/STORAGE.md`）

## 內容

| 元件 | 說明 |
|---|---|
| `AirmsApplication` / `MainVerticle` | Vert.x 5 啟動：讀 config.json 與 secrets.json → 檢查 HTTPS 憑證 → 讀路網設定 → 檢查資料目錄（標記檔、單一程式鎖）→ 開資料庫並確認結構 → 啟動抓取、即時資料整理、資料保留、備份 → 開 HTTPS（TLS 1.3）。設定類錯誤只印說明、不印程式堆疊 |
| `config/AppConfig`、`Secrets`、`TlsKeystore` | 設定一次讀入並驗證，錯誤全部列出；密碼只從環境變數 `AIRMS_TLS_KEYSTORE_PASSWORD` 或 secrets.json 讀；啟動時先檢查憑證檔與密碼 |
| `storage/DataVolume`、`DataDirLock` | 資料目錄防呆：沒有 `.airms-volume` 標記檔就拒絕啟動；同一資料目錄只允許一個程式（作業系統檔案鎖，強制結束時自動釋放） |
| `db/Db`、`Schema`、`MonthlyStore`、`Series` | SQLite：`core.db`（帳號、設定、紀錄）＋各系列月檔（`vd`、`section`、`rms`、`feedlog`，每月一個檔）＋記憶體資料庫（畫面用的最新一筆）。每個檔（每個系列）一條寫入執行緒；WAL；以 application_id／user_version 認檔，不認得或版本較新的檔拒絕使用，舊版自動升級 |
| `feed/FeedHttpClient` | 下載限制：連線 10 秒、閒置 15 秒、整體 30 秒、8 MB 上限、不跟隨轉址、不接受壓縮（數值可在 config.json 調整） |
| `feed/SafeXml` | 不處理 DTD 與外部實體；限制元素數、深度、屬性長度；截斷或格式錯誤整份拒絕 |
| `feed/RawXmlArchive` | 原始 XML gzip 歸檔到 `cache/xml_raw/<來源>/yyyy/MM/dd/`（依收到時間，台北），先寫暫存檔再改名；啟動時清除 10 分鐘以上的暫存檔 |
| `feed/FeedVerticle` | 每個來源一個：下載 → 雜湊（內容沒變就結束）→ 解析 → 歸檔 → 寫入該月的月檔 → 更新記憶體最新資料 → 記錄抓取結果；一輪結束才排下一輪。啟用、網址、間隔每一輪讀系統設定，網頁上切換不必重啟 |
| `parse/*Parser` | VD、路段、RMS 解析；原值照存，單欄有問題只記錄不整份丟棄 |
| `repo/*Repository` | VD 全量（14 欄原值，同一份內容只存一次）、路段與 RMS 歷史（同時間只存一筆）、抓取紀錄與原始檔索引 |
| `retention/RetentionService` | 依系統設定刪除過期的原始 XML、月檔、程式 log（見 `docs/STORAGE.md`）；啟用備份時只刪已備份的 |
| `backup/BackupService` | 每天備份到外接硬碟（config.json 的 `backup`，測試機關閉；見 `docs/STORAGE.md`） |
| `http/WebServer` | 資安標頭；每個回應新的隨機 CSP nonce；寫入請求本文 64 KB 上限、不收上傳檔；錯誤只回通用訊息；`/api/health`（需要登入時，未登入只回整體狀態） |

## 停機重跑的處理

- 同一資料目錄只允許一個程式，第二個指向同一目錄的程式拒絕啟動。
- `core.db` 的 `service_run`：每次啟動一列、每分鐘心跳、正常停止時記時間；上次不是正常停止時，啟動 log 列出停機區間（這段期間沒有抓取資料）。
- 原始檔歸檔先寫暫存檔再改名；同一天已有同雜湊的檔就沿用，重抓不會重複歸檔、重複寫入。
- 記憶體中的最新資料在重啟後清空，下一輪抓取（約 1 分鐘內）恢復。

## 和舊系統不同的地方

- RMS 某欄缺值（例如 RMS-N3-S-182 有時缺 `rms_rate`）時：舊系統整份標為部分失敗、每分鐘重試；新系統照存該列（缺的欄位為 NULL）並記錄問題。
- 路段最新資料的主鍵加上國道與方向，國1／國3 里程相同時不會互相覆蓋。
- VD 存全部約 1,486 支、3,205 個車道的 14 欄原值（-2 照存），不再只存 8 支的流量加總。
- 屏柵線告警改由 VD 原值計算（P3），無效車道的時段標為資料異常，不把 -2 加進總量。
- 原始 XML 三種來源都保存，作為來源檔案結構有問題時的證據。
- 不再使用 MongoDB、API 回傳的 AES 加密、固定 CSP nonce；舊系統的測試用 TCP 端點改成開發用工具 `tools/airms-sim`（P4）。
